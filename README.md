# Shop Website

A learning project to build and commercialize a shop website: React + Tailwind, deployed on Vercel, with an AI agent powered by the SuperIntern SDK.

## Stack

- [Vite](https://vite.dev/) + React + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/)

## Getting started

```bash
npm install
npm run dev
```

## Milestones

1. **Setup React project** — Vite + React + Tailwind (done)
2. **Setup Vercel** — connect this repo to Vercel for deployment
3. **Setup SuperIntern SDK** — add an AI agent to the site ([dashboard](https://test-app.superintern.ai/dashboard/api_messages))

Product photos and copy go in `src/assets` and `src/App.tsx`.
